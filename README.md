<h3 style="color: #800000;">▸ Recent Projects</h3>

<table width="100%" style="border: none; border-collapse: collapse;">
<tr style="border: none;">
<td width="50%" valign="top" style="border: 1px solid #333; padding: 15px;">
<b>[TornadoRevC2]</b><br>
<sub style="color: #A3A3A3;">Modular Post-Exploitation Framework</sub><br><br>
Lightweight C2 framework in Python for Linux & Windows. Supports reverse/bind shells over TCP, TLS, mTLS, 63+ plugins, SOCKS5 pivoting, in-memory payload execution, and SHA-256 verified file transfers.
</td>
<td width="50%" valign="top" style="border: 1px solid #333; padding: 15px;">
<b>[XXERipper]</b><br>
<sub style="color: #A3A3A3;">Black-Box XXE Scanner</sub><br><br>
Open-source XXE scanner supporting 30+ attack techniques (in-band, blind/OOB, SSRF, cloud metadata, WAF bypass). Features differential parser fingerprinting, confidence scoring, and JSON/SARIF/HTML reporting.
</td>
</tr>
<tr style="border: none;">
<td width="50%" valign="top" style="border: 1px solid #333; padding: 15px;">
<b>[CorsRipper]</b><br>
<sub style="color: #A3A3A3;">Advanced CORS Security Assessment</sub><br><br>
Detects and correlates exploit chains: credentialed CORS, CSRF bypass, OAuth token exposure, WebSocket Origin trust, GraphQL introspection, CDN cache poisoning, postMessage abuse, and timing side channels.
</td>
<td width="50%" valign="top" style="border: 1px solid #333; padding: 15px;">
<b>[Enterprise AI-based IDS]</b><br>
<sub style="color: #A3A3A3;">AI-Powered Intrusion Detection System</sub><br><br>
Modular network security monitoring platform combining real-time packet capture, hybrid AI models, behavioral heuristics, and threat intelligence. Flask dashboard, Zeek integration, multi-process resilient architecture.
</td>
</tr>
<tr style="border: none;">
<td width="50%" valign="top" style="border: 1px solid #333; padding: 15px;">
<b>[StaticSentinel]</b><br>
<sub style="color: #A3A3A3;">YARA-based Static Malware Analysis</sub><br><br>
Assesses files without executing them using YARA rule matching, entropy analysis, SHA-256 hashing, and VirusTotal lookups. Heuristic scoring reduces false positives and provides human-readable verdicts.
</td>
<td width="50%" valign="top" style="border: 1px solid #333; padding: 15px;">
<b>[Libvirt/KVM VM Migration Tool]</b><br>
<sub style="color: #A3A3A3;">Data-Integrity-First VM Export/Import</sub><br><br>
Open-source utility for exporting and importing KVM virtual machines. Every file SHA-256 verified, qcow2 backing chains validated, authenticated encryption with GnuPG and OpenSSL, plus hardening against twelve classes of Bash failure modes.
</td>
</tr>
